# Proposal: add-internet-speed-ping

## Why

README.md проекта содержит задание: написать скрипт-замерятель скорости интернета. Скрипт должен принимать URL, делать последовательно 10 запросов к «тяжёлой картинке», замерять время и объём, выводить среднюю скорость в МБ/с. Задание дано как часть подготовки к собеседованию — поэтому качество кода (читаемость, обработка ошибок, CLI-гигиена) важнее количества фич.

## What Changes

- Добавляется скрипт `ping.py` в корне проекта — единственный исполняемый модуль.
- Скрипт принимает URL обязательным аргументом (`--url`), опционально `--count` (default 10), `--timeout` (default 10 секунд), `--json` (машиночитаемый вывод).
- Делает `count` последовательных HTTP GET к указанному URL через `httpx.AsyncClient` с `stream=True`; для каждого запроса замеряет время от старта до получения последнего байта через `time.perf_counter`.
- Печатает отчёт: aggregate МБ/с (total_bytes / total_time) и per-request статистику (min/max/mean Mbps) + счётчик упавших запросов.
- Partial failures не маскируются: упавший запрос инкрементирует `failed`, остальные продолжаются; exit code = 1 при любом failed, 0 если все успешны, 2 при невалидном URL.
- Добавляется зависимость `httpx` в `.venv` (через `pip install httpx`).
- Добавляется `tests/test_speed_report.py` с unit-тестами на чистую математику агрегации (без моков сети).
- README проекта дополняется разделом «Usage» с примером запуска.


## Capabilities

### New Capabilities

- `cli-ping`: требования к поведению скрипта-замерятеля скорости интернета — CLI-интерфейс, формат вывода, обработка ошибок, семантика замера.

### Modified Capabilities

Нет. Это первая capability в проекте.
